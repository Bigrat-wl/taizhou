# 后台操作手册

> 给**组织者（老师/管理员）**看的操作说明。
> 后台地址：`https://ratzu.art/?admin`（把域名换成你的实际域名）

---

## 一、进入后台

打开 `https://<你的域名>/?admin`，页面会要求输入**后台口令**（`ADMIN_KEY`）。

- 口令由部署时在服务器上配置（`/var/www/taizhou/deploy/ecosystem.config.cjs`）。
- 输错会提示重新输入；输入正确后进入后台。
- 口令保存在浏览器会话中，**关闭浏览器后需重输**（这是安全设计）。
- 右上角「**退出后台**」可清除口令。

> ⚠️ 后台是**独立入口**，学生看不到、也进不来——学生访问 `https://<域名>/` 是答题页。

---

## 二、准备学生名单

### 名单文件格式

支持 **Excel（`.xlsx`）** 或 **CSV**。**第一行必须是表头**，从第二行开始是学生数据。

**必需列**（缺了会导入失败）：

| 列名 | 说明 |
|------|------|
| 学号 | 学生的唯一标识，**不能重复、不能为空** |
| 姓名 | 学生姓名，不能为空 |

**选填列**：

| 列名 | 说明 |
|------|------|
| 学院 | 如「计算机学院」 |
| 班级 | 如「计算机2604」 |

**示例**：

| 学号 | 姓名 | 学院 | 班级 |
|------|------|------|------|
| 2026000001 | 李明悦 | 计算机学院 | 计算机2604 |
| 2026000002 | 黄子言 | 外国语学院 | 英语2604 |
| 2026000003 | 王雨安 | 外国语学院 | 英语2601 |

### 表头写法的容错

表头**大小写不敏感、前后空格自动去除**，以下写法都能识别：

| 列 | 可接受的表头写法 |
|----|----------------|
| 学号 | `学号`、`studentId`、`student_id`、`id`、`编号` |
| 姓名 | `姓名`、`name`、`名字` |
| 学院 | `学院`、`college`、`院系` |
| 班级 | `班级`、`class`、`class_name`、`classroom` |

**多余列会被忽略**（比如从报名系统导出时带了一堆字段，不影响导入）。

### 常见问题

| 情况 | 结果 |
|------|------|
| 学号或姓名为空的行 | **自动跳过**（该行不导入） |
| 学号重复 | 只保留一条（后出现的覆盖先出现的） |
| 文件不含「学号」或「姓名」列 | 导入失败，提示「名单为空或缺少「学号」「姓名」列」 |
| CSV 是 GBK 编码 | ⚠️ 可能乱码，建议先另存为 UTF-8 或直接用 xlsx |

## 三、导入名单

1. 后台页面上方点「**导入名单**」。
2. 选择准备好的 xlsx / csv 文件。
3. **如果系统里已有数据**，会弹出确认框，写明：
   > 将清空 N 名学生、M 条答案、K 个上传

   ⚠️ **导入是"清空重来"**：会把**所有**学生、答案、上传记录、登录状态全部删除，再写入新名单。

   - **比赛前导入**：正常操作，确认即可。
   - **比赛中导入**：**千万别点**——学生会全部被清掉，答案丢失。

4. 确认后导入，页面提示「成功导入 N 人」。

> 💡 **如果只是补录个别学生**（名单基本没错、只想加一个人），**不要重新导入整个名单**——用「添加学生」按钮单独加。

---

## 四、添加单个学生

1. 点「**添加学生**」按钮。
2. 填写：学号、姓名（必填）+ 学院、班级（选填）。
3. 提交 → 列表出现该学生。
4. 学号已存在会提示「该学号已存在」。

---

## 五、设置开赛时间

学生登录后会看到**开赛倒计时**，到点才能开始答题。

1. 在后台设置**开赛时间**。
2. 设置后：
   - 学生登录 → 看到倒计时，「开始答题」按钮**灰色不可点**。
   - 到点后 → 按钮自动可点。
3. **不设置开赛时间** = 视为**已开赛**，学生登录后可直接答题。

> 💡 想让学生"先登录等着、到点统一开始"，就设一个未来的时间。

**⚠️ 时间格式**：请使用带时区的 ISO 格式（如 `2026-09-20T09:00:00+08:00`），不带时区可能偏 8 小时。

## 六、看提交状态

列表每行显示一个学生的状态：

| 列 | 含义 |
|----|------|
| **学号 / 姓名 / 学院** | 基本信息 |
| **已填进度** | 已填的小问数 / 总小问数（如 `18/50`） |
| **交卷** | 是否已点「提交答卷」 |
| **登录状态** | 当前是否在系统里（有有效登录） |
| **得分** | 已评总分 / 满分 100；**未评**表示还没批 |
| **xlsx / zip** | 实践题成果是否已上传 |
| **操作** | 「批卷」按钮（**未交卷的学生不能批**） |

**展开某一行** → 看到该学生**每题**的填写状态（22 个方块）：

- 🟩 **全填**（该题所有小问都填了）
- 🟨 **部分填**（有角标如 `3/5`）
- ⬜ **未填**

点「**刷新**」可拉取最新状态；点「**导出 CSV**」下载全部答案。

## 七、批卷

点某个学生行的「**批卷**」→ 进入**三栏批卷页**：

```
┌─────────┬──────────────────┬──────────────┐
│ 题号索引 │   批卷主区        │  学生列表     │
│ Q11 ●   │  题面 + 学生答案  │ [上一份][下一份]│
│ Q12 ○   │  底部打分框       │  已评 6/12    │
│  ...    │                  │  ──────────  │
│ Q22 ○   │                  │  李明悦 ✓已批 │
└─────────┴──────────────────┴──────────────┘
```

**怎么用**：

1. **左栏**：22 道题的索引，点题号跳到该题；实心=已评、空心=未评。
2. **中栏**：每题显示**题目原文 + 学生的答案**（带小问），**题目底部有打分框**。
   - 只有**计分题（11–22）**能打分，画像题（1–10）只显示不打分。
   - 输入分数后**自动保存**。
3. **中栏末尾**：学生的**实践题成果**（xlsx / zip），点「预览」可看：
   - xlsx：分页表格，可切换 5 张工作表。
   - zip：只列文件清单（不渲染网页内容，安全考虑）。
4. **右栏**：
   - 顶部「**上一份 / 下一份**」在已交卷学生间切换，不用退回列表。
   - 下方是全部学生列表，点击可跳转，当前学生高亮。
   - 状态标注：**未交卷**（不可点）/ **已评 N/12** / **已批完**。

**总分**显示在中栏顶部，随打分实时更新。

---

## 八、导出与统计

点「**导出 CSV**」下载全部学生的答案：

- 一行一学生，列含 学号/姓名/学院/班级/是否交卷/**各题答案**/**各题得分**/总分。
- 带 UTF-8 BOM，**Excel 可直接打开**（不乱码）。
- 带小问的题，各小问答案拼在同一格内（`①②③` 分行）。

## 九、比赛当天操作清单

| 时间 | 做什么 |
|------|--------|
| **赛前** | 导入名单 → 设置开赛时间 → （可选）让几个测试账号先走一遍 |
| **开赛** | 到点学生自动可答题；在后台看「已填进度」了解进度 |
| **赛中** | ⚠️ **不要点「导入名单」**（会清空所有人） |
| **收卷后** | 看「交卷」列确认谁交了；点「批卷」逐个打分 |
| **批完** | 「导出 CSV」存档 |

## 十、常见问题

**Q：学生登录提示"学号或姓名不对"？**
A：检查该学生是否在名单里、学号姓名是否**完全一致**（重新导入或「添加学生」补上）。

**Q：学生说答不了题？**
A：检查是否设了开赛时间且还没到点。

**Q：手滑点了「导入名单」怎么办？**
A：**无撤销**。答案和上传都会丢。比赛前请务必谨慎。

**Q：后台进不去？**
A：口令错误，或服务器配置有变。联系部署者确认 `ADMIN_KEY`。

**Q：学生上传的文件看不了？**
A：批卷页底部「实践题成果」里点「预览」；xlsx 超过 1000 行的部分不显示，可导出后查看完整文件。
